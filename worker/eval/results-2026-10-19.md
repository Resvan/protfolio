## Fixes made because of this evaluation

- Prompt lists the exact case-study URLs instead of a guessable `/projects/<slug>/` pattern.
- Context carries precomputed facts (`3+` years, company/project counts); the model no longer does date maths ("over 2 years" was wrong).
- Training entries removed from the context (a bootcamp was listed as an employer).
- Malayalam answers get 700 output tokens and at most 3 list items (they were cut off at 300).
- Declines mention only the topic asked about; Malayalam uses നോട്ടീസ് പീരിയഡ് for "notice period".
- Contact marker stripped together with the preceding space.
- Server never returns an empty answer; failure reasons are logged (never message text).
